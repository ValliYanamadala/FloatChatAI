# ARGO Core Concepts

ARGO is documented in this project as a global network of autonomous profiling floats.

A profiling float is an autonomous instrument that descends and ascends while recording ocean observations.

A profile is a vertical set of measurements collected during one float cycle at approximately one location and time. Measurements in a profile should be interpreted together by depth or pressure.

A trajectory is the sequence of geographic positions of a float across time. A trajectory describes movement, not a vertical profile.

BGC means biogeochemical observations. The current project glossary lists oxygen, chlorophyll, and nitrate as BGC examples.
